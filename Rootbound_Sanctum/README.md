# Rootbound Sanctum — map and research

## Open from this folder

Double-click **Open_Map.bat** to run the voxel map in the existing Goblin Viewer project.

Double-click **Open_Plan.bat** to open the approved plan and research in your browser. You can also open **Plan/review.html** directly.

## Contents

- **Plan/**: revision B review, top-down floor plan, progression diagram, research text, source index, design data, and review checks.
- **Sources/**: the saved research excerpts that existed in the original review folder.
- **Screenshots/**: six real renders of the voxel map, including the overview and monster-scale views.
- **copy-manifest.json**: the source paths and checksums of the copied documents and images.

## Live map, not a second project copy

The map launcher uses the live scene at **../scenes/rootbound_sanctum.tscn**. The scripts, monster assets, and scale data stay in their normal project folders. Changes to the live map therefore appear here without a separate map copy.

The detailed map notes remain at **../docs/rootbound_sanctum.md**. The existing viewer launcher and dungeon are unchanged.

The plan, research excerpts, and screenshots in this folder are a delivery snapshot. Their original copies remain in the Hermes artifact folder. The review page is self-contained; external source links still need an internet connection.
